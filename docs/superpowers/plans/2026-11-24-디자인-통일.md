# 세 화면 디자인 통일 구현 계획

> **에이전트에게:** superpowers:executing-plans 로 한 과제씩 실행한다. 단계는 `- [ ]`.

**목표:** 티비의 색·글꼴 값을 `design/tokens.json` 한 곳에 두고, 문서 모음과 인쇄 카드가 그 값을 써서 셋이 한 옷을 입는다.

**방법:** `tokens.json`이 원본. `design/build_tokens.py`가 그 값을 `docs/index.html`의 `:root` 블록에 주입한다(문서 모음은 한 파일로 유지). `cards/cards.py`는 `tokens.json`을 직접 읽는다. 티비는 읽기만 하고, 티비 CSS 변수와 `tokens.json`이 어긋나면 `tools/tvtest.py`가 FAIL.

**기술:** 단일 HTML, Pillow, fontTools(subset), playwright + `/usr/bin/google-chrome`.

**설계 문서:** `docs/superpowers/specs/2026-11-24-디자인-통일-design.md`

## 전역 제약

- 티비(`tv/source.html`)는 **읽기만** 한다. 이 계획의 어떤 과제도 티비를 고치지 않는다.
- 커밋 하나 = 수정 하나, 바로 `git push origin main`, `--force` 금지.
- `submission-2026-11-22/` 는 손대지 않는다.
- 질감(스캔라인·유리광·나무결 바탕)은 옮기지 않는다. 나무결은 문서 모음 맨 위 띠 한 줄만.
- 내용은 바꾸지 않는다. 예외는 소개서의 틀린 숫자 둘뿐(과제 3).
- 글꼴은 티비의 셋: 고운바탕(본문) · 나눔고딕코딩(라벨·코드) · VT323(라틴 번호만).

## 눈여겨볼 것

- VT323에 한글이 없다 → 코드(`8ㅎ8ㅎ`)를 VT323으로 찍으면 빈 네모. 과제 2에서 글자 덮임을 검사한다.
- 고운바탕 subset에 없는 글자를 카드가 쓰면 빈 네모로 인쇄된다 → 과제 2에서 빌드가 멈추게 한다.
- 티비에서 그대로 가져오지 않은 값(`panel` `raise` `line` `phos-dim` `slate`)까지 대조하면 검사가 처음부터 FAIL → 과제 1에서 대조 범위를 여덟 개로 못박는다.
- 문서 모음을 어둡게 하면 인쇄가 온통 검정 → 과제 3에서 `@media print` 를 넣는다.
- 옛 `prefers-color-scheme:dark` 블록이 남아 있으면 어두운 기기에서 색이 두 번 덮인다 → 과제 3에서 지운다.

### 과제 1: 값 한 곳에 모으기

**파일:** 만든다 `design/tokens.json`, `design/build_tokens.py` · 고친다 `tools/tvtest.py`

**내보내는 것:**
- `design/tokens.json` — `{"color":{<이름>:"#rrggbb"},"font":{"serif":[...],"mono":[...],"digit":[...]},"fromTv":[<티비에서 그대로 가져온 색 이름들>]}`
- `python3 design/build_tokens.py` — `docs/index.html` 안의 `/*TOKENS*/ … /*\/TOKENS*/` 사이를 `tokens.json`에서 만든 CSS 변수로 갈아 끼운다. 바뀐 게 없으면 아무것도 쓰지 않는다.
- `design/build_tokens.py` 의 `load_tokens() -> dict` — 다른 스크립트가 쓰는 입구.

- [ ] **1. `tokens.json` 을 쓴다**

색 열세 개와 글꼴 셋. 값은 설계 문서의 "색" 표 그대로. `fromTv` 에는 티비에서 그대로 가져온 여덟 개만 넣는다: `bg` `phos` `amber` `red` `ochre` `violet` `wood` `wood2`.

- [ ] **2. 검사부터 더한다**

`tools/tvtest.py` 에 검사 하나: `fromTv` 의 색마다 티비의 짝이 되는 CSS 변수 값과 글자까지 같다. 짝은 `bg→--room` `phos→--phos` `amber→--amber` `red→--red` `ochre→--ochre` `violet→--violet` `wood→--wood` `wood2→--wood2`. 돌려서 통과를 본다(값이 맞게 적혔으면 바로 OK, FAIL이면 `tokens.json` 이 틀린 것이다).

- [ ] **3. `build_tokens.py` 를 쓰고 `docs/index.html` 에 자리를 낸다**

`docs/index.html` 의 `:root{…}` 줄을 `/*TOKENS*/` 와 `/*\/TOKENS*/` 로 감싼다. 값 자체는 아직 바꾸지 않는다 — 이 과제는 통로만 뚫는다.

- [ ] **4. 돌려서 확인한다**

`python3 design/build_tokens.py && python3 tools/tvtest.py` → 전부 OK, `git diff` 에 `docs/index.html` 변화 없음(아직 같은 값).

- [ ] **5. 커밋·푸시**

### 과제 2: 글꼴 넣기

**파일:** 만든다 `design/fonts/VT323.ttf`, `design/fonts/NanumGothicCoding.ttf`, `design/fonts/GowunBatang-subset.ttf`, `design/make_fonts.py`

**쓰는 것:** 과제 1의 `load_tokens()`.

**내보내는 것:** `design/make_fonts.py` — npm `@fontsource/{vt323,nanum-gothic-coding,gowun-batang}` 를 받아 woff2→ttf 로 바꾸고, 고운바탕은 카드에 쓰이는 글자만 남겨 저장한다. `design/fonts/chars.txt` 에 그 글자 집합을 적어 둔다.

- [ ] **1. 검사부터 쓴다**

`design/make_fonts.py` 안에 `check_coverage(ttf_path, chars) -> list` — 글꼴에 없는 글자를 돌려준다. 그리고 `cards/cards.py` 가 그리기 전에 이걸 불러 하나라도 없으면 `SystemExit` 로 멈추게 할 자리를 정해 둔다(과제 4에서 연결).

- [ ] **2. `make_fonts.py` 를 쓴다**

글자 집합은 `cards/cards.py` 의 `CARDS`(특수 카드 본문 포함)와 고정 문구에서 모은다. 여기에 한글 자모·숫자·영문·문장부호를 더한다. `fontTools.subset` 으로 고운바탕을 줄인다.

- [ ] **3. 돌리고 크기를 확인한다**

`python3 design/make_fonts.py` → 세 파일 생성. 고운바탕 subset 이 1MB 미만. `check_coverage` 가 빈 목록.

- [ ] **4. 커밋·푸시** (글꼴 파일 포함)

### 과제 3: 문서 모음 다시 입히기

**파일:** 고친다 `docs/index.html` · 만든다 `tools/docstest.py`

**쓰는 것:** 과제 1의 `build_tokens.py`, 과제 2의 `design/fonts/`.

- [ ] **1. 검사부터 쓴다**

`tools/docstest.py` — 헤드리스로 `docs/index.html` 을 열고: ① `body` 배경이 `#0b0908` ② 본문 글꼴 이름에 `Gowun Batang` ③ 고른 탭 색이 `#e7b55a` ④ 소스에 `prefers-color-scheme` 이 없다 ⑤ 소스에 `@media print` 가 있다 ⑥ 본문에 "카드 31장" 이 있고 "카드 22장" 이 없다 ⑦ 콘솔 오류 없음. 돌려서 FAIL 을 본다.

- [ ] **2. 색과 글꼴을 바꾼다**

`:root` 를 `tokens.json` 값으로(과제 1의 통로). `prefers-color-scheme` 블록과 `data-theme` 블록을 지운다. 본문 글꼴을 고운바탕, 라벨·표 머리·코드를 나눔고딕코딩으로. 글꼴은 Google Fonts `<link>` 로 불러온다(문서 모음은 온라인에서 본다).

- [ ] **3. 생김새를 맞춘다**

맨 위 4px 나무결 띠(`wood`→`wood2`). 탭은 `01`~`10` 번호(VT323) + 이름, 고른 것만 `amber` 에 얇은 밑줄. 본문 17px, 줄 간격 1.85. 제목 아래 선은 `amber`.

- [ ] **4. `@media print` 를 넣는다**

흰 바탕·검은 글씨, 나무결 띠와 탭 숨김.

- [ ] **5. 틀린 숫자 둘을 고친다**

소개서 구성 줄의 "카드 22장" → "카드 31장", 그 아래 "엔딩은 다섯" → "엔딩은 아홉". (설계에서 허용한 예외. 공모전 페이지에 틀린 숫자를 남길 수 없다.)

- [ ] **6. 검사를 돌리고 눈으로 본다**

`python3 tools/docstest.py` → 전부 OK. 화면을 찍어 읽히는지 본다.

- [ ] **7. 커밋·푸시하고 아티팩트에 게시한다** (`docs/index.html`, root 는 `docs/`)

### 과제 4: 카드 다시 입히기

**파일:** 고친다 `cards/cards.py` · 지운다 `cards/ext/`

**쓰는 것:** 과제 1의 `load_tokens()`, 과제 2의 `design/fonts/` 와 `check_coverage`.

- [ ] **1. 색을 `tokens.json` 에서 읽는다**

`cards.py` 상단의 `BG` `PANEL` `LINE` `WHITE` `GRAY` `ORA` `ORA2` 와 `ACT` 의 막 색을 `load_tokens()` 값에서 만든다. 막 색: 현행범 `ochre` · 맥주집 `slate` · 반지하 `red` · 자수서/엔딩 `amber` · 특수 `violet`.

- [ ] **2. 글꼴을 바꾼다**

`F()` 가 Noto Sans CJK 대신 고운바탕(본문)·나눔고딕코딩(라벨·코드)을 쓰게 한다. 카드 번호(`K6` `X1` `E1`)만 VT323. 코드(`8ㅎ8ㅎ`)는 나눔고딕코딩 — VT323에 한글이 없다.

- [ ] **3. 뒷면 그림을 버린다**

`BACKSRC` 와 그 분기를 지우고 현장 카드 뒷면도 `back_button()` 으로 그린다. `cards/ext/` 를 지운다.

- [ ] **4. 글자 덮임 검사를 연결한다**

그리기 전에 `check_coverage` 를 불러 빠진 글자가 있으면 멈춘다.

- [ ] **5. 뽑아서 본다**

`python3 cards/cards.py png && python3 cards/make_pdf.py` → 31장. 앞뒤 전체비교 PNG 를 보고 티비 화면과 같은 옷인지 확인한다.

- [ ] **6. 커밋·푸시**

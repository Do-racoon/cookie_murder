# 자수서는 일기장으로 연다 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 범인은 3막 범인의 질문("그녀는 왜 쿠키를 먹을까")을 맞혀야 자수서 S1·S2를 낼 수 있게 하고, 티비·기획서·핸드아웃·문서 모음을 그 규칙으로 맞춘 뒤 아티팩트에 게시한다.

**Architecture:** 티비(`tv/source.html`)에 `confessOpen()` 하나를 더해 판결 화면과 `setVerdict`가 그것을 본다. 기획서·핸드아웃은 Claude 문서에서 고치고 markdown으로 내보내 `text/`에 넣는다. 문서 모음(`docs/index.html`)의 기획서 탭은 `text/기획서.md`에서 다시 그리고, 룰북 탭은 손으로 고친다.

**Tech Stack:** 단일 HTML(바닐라 JS), Python 3 + Playwright(`tools/tvtest.py`), `tools/build.py`, Claude Docs 커넥터, Artifact 도구.

**Spec:** `docs/superpowers/specs/2026-11-24-자수서-조건-design.md`

## Global Constraints

- 저장소 규칙은 `CLAUDE.md` 그대로: 고치기 전 `git pull --rebase origin main`, 수정 하나 = 커밋 하나, 바로 `main`에 푸시, `--force` 금지.
- 점수표(기획서 10절의 "점수" 표)는 **고치지 않는다** (사용자: "점수표는 일단 보류").
- 엔딩 조합표 `VGRID`는 그대로.
- 그녀가 어머니를 죽였다는 문장은 어디에도 넣지 않는다.
- 티비 설계를 바꾸므로 `DEFAULT_DATA.version`을 pull 받은 값 + 1로 올린다 (지금 33 → 34).

## Review Focus

1. 판결 화면에 들어간 뒤에 범인이 질문을 맞힌 경우 — 잠겨 있던 S1·S2가 바로 열려야 한다.
2. 질문을 맞히지 않았는데 "자수서를 쓰지 못했다"를 고르는 것은 언제나 된다 — 엔딩 3·4·5로 가야 한다.
3. "처음부터 다시 적는다"(reset) 뒤에도 잠금 상태가 그대로 계산돼야 한다.
4. 옛 저장 상태(`memPart`가 없는 S)로 열어도 `confessOpen()`이 오류 없이 false를 돌려야 한다.
5. 형사 쪽 질문(다리)만 맞히고 4막에 들어간 일반 경로에서 판결 화면이 잠금 안내를 보여야 한다.

### Task 1: 티비 — 자수서 잠금

**Files:**
- Modify: `tv/source.html` (`DEFAULT_DATA.version`, 판결 블록 `VQ`/`setVerdict`/`verdictHtml` 근처)
- Modify: `tools/tvtest.py`
- Generated: `tv/index.html`, `docs/tv.html` (`python3 tools/build.py`)

**Interfaces:**
- Produces: `confessOpen(): boolean` — `S.memPart.D[3]`에 3막 질문 묶음(`D.memory`에서 `from===3`)의 `optional:true` 질문 인덱스가 들어 있으면 true. `S.memPart`가 없으면 false.

- [ ] **Step 1: 실패하는 검사를 `tools/tvtest.py`에 더한다** (기존 version 검사는 34로)

```python
check("DEFAULT_DATA.version 이 34 다", ver == 34, ver)
r = pg.evaluate("""(()=>{ setRoleCode("TV","T9"); start();
  const a=confessOpen(); setVerdict("confess","S1"); const b=(S.verdict||{}).confess;
  setVerdict("confess","none"); const c=S.verdict.confess; setVerdict("reset","");
  S.act.D=3; S.memDone.D=[1,2]; enterCode("G2"); answerMemory("피를 좋아하니까");
  const d=confessOpen(); setVerdict("confess","S1"); const e=S.verdict.confess;
  const S0=S; S={...S0}; delete S.memPart; const f=confessOpen(); S=S0;
  return {a,b,c,d,e,f}; })()""")
check("처음에는 자수서가 잠겨 있다", r["a"] is False, r)
check("잠겨 있으면 S1을 골라도 적히지 않는다", r["b"] is None, r)
check("못 썼다는 언제나 고를 수 있다", r["c"] == "none", r)
check("3막 범인의 질문을 맞히면 열린다", r["d"] is True, r)
check("열린 뒤에는 S1이 적힌다", r["e"] == "S1", r)
check("memPart 없는 옛 상태에서도 false", r["f"] is False, r)
```

- [ ] **Step 2: 실패를 확인한다**

Run: `python3 tools/build.py && python3 tools/tvtest.py`
Expected: `FAIL DEFAULT_DATA.version 이 34 다`, `confessOpen is not defined` 로 콘솔 오류 FAIL.

- [ ] **Step 3: `tv/source.html` 구현**

- `version` 33 → 34.
- `confessOpen()` (Interfaces 그대로).
- `setVerdict(k,val)`: `k==="confess"`이고 `val`이 `"S1"`·`"S2"`인데 `!confessOpen()`이면 `toast("그녀의 이유를 아직 모른다 — 자수서를 쓸 수 없다.")` 하고 아무것도 적지 않는다.
- `verdictHtml()`: 자수서 질문을 그릴 때 `!confessOpen()`이면 S1·S2 버튼에 `disabled`를 주고, 버튼 목록 아래에 한 줄
  `그녀가 왜 쿠키를 먹는지 맞혀야 자수서를 쓸 수 있다. 아직 "4 기억"의 범인의 질문이 열려 있다.`

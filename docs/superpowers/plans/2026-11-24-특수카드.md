# 특수 카드 · 일기장 · 알림 띠 구현 계획

> **에이전트에게:** 이 계획은 superpowers:executing-plans 로 한 과제씩 실행한다. 단계는 `- [ ]` 로 표시한다.

**목표:** 사진 지점을 누르면 티비가 "특수 카드를 꺼내라"고 지시하고, 증언·감정서·일기장 전문이 그 종이 카드에 실린다.

**방법:** 핫스팟에 `card`·`only` 칸을 더하고, 본문은 `DEFAULT_DATA.specials` 에 둔다. 티비는 본문을 띄우지 않고 지시만 한다(일기장이 범인에게 새지 않게). 인쇄는 `cards/cards.py` 에 X 여섯 장을 더해 28장으로 다시 뽑는다.

**기술:** 단일 HTML(`tv/source.html`) + `tools/build.py`, Pillow(`cards/cards.py`), ReportLab(`cards/make_pdf.py`), 검증은 playwright + `/usr/bin/google-chrome`.

**설계 문서:** `docs/superpowers/specs/2026-11-24-특수카드-design.md`

## 전역 제약

- `tv/source.html` 이 원본. 고친 뒤 반드시 `python3 tools/build.py`.
- 커밋 하나 = 수정 하나. 고치면 바로 `git push origin main`. `--force` 금지.
- `DEFAULT_DATA.version` 을 31 → 32 로 올린다 (옛 저장값을 새 설계로 바꾸는 신호).
- `submission-2026-11-22/` 는 손대지 않는다.
- 특수 카드 본문을 플레이 화면에 띄우지 않는다. 제작자 모드에서만 보인다.
- 그녀가 어머니를 죽였다는 것은 어느 카드에도 쓰지 않는다.
- 커밋 메시지는 한국어 + 세션 attribution 두 줄.

## 눈여겨볼 것

- 옛 저장값(localStorage)에 `version:31` 이 남은 폰에서 특수 카드가 없는 채로 열린다 → 과제 2 에서 version 올림으로 덮어쓴다.
- `only:"D"` 지점을 범인이 눌렀을 때 — 범인 화면에도 "꺼내라"가 뜨면 일기장이 샌다. 과제 3 에서 범인 쪽에는 지시를 숨긴다.
- E2 엔딩 코드가 티비에는 `졼트브레드`, 인쇄 카드에는 `쇼트브레드` 로 어긋나 있다 → 과제 2 에서 고친다.
- 3막에는 사진 카드가 없다 → X6 은 G1 본문의 `▣` 지시로 연다.
- 새 지점이 기존 지점과 겹치면 하나가 눌리지 않는다 → 과제 3 의 좌표는 기존 좌표와 거리를 둔 값으로 못박았다.

### 과제 1: 검증 스크립트

**내보내는 것:** `python3 tools/tvtest.py` — `tv/index.html` 을 헤드리스로 열어 검사 결과를 줄마다 `OK`/`FAIL` 로 찍고, FAIL 이 하나라도 있으면 종료코드 1.

- [ ] **1. 스크립트를 쓴다**

playwright sync API + `/usr/bin/google-chrome`, `--allow-file-access-from-files`. 검사 항목은 함수 하나당 하나로 두고, 지금은 두 개만 넣는다: 콘솔 오류가 없다 / `DEFAULT_DATA.version` 이 31 이상이다.

- [ ] **2. 돌려서 통과를 본다**

`python3 tools/tvtest.py` → 두 줄 다 `OK`, 종료코드 0.

- [ ] **3. 커밋·푸시**

### 과제 2: 알림 띠를 아래로, 엔딩 코드 오타, 판 올림

**파일:** 고친다 `tv/source.html` (`.ticker` CSS 90~94행 근처, `paintTick()`, `"version"`, E2 `code`)

- [ ] **1. 검사부터 더한다**

`tools/tvtest.py` 에 검사 셋을 더한다: ① 알림을 띄운 뒤 `#ticker` 의 화면 위 좌표가 `.body` 첫 줄보다 아래다 ② `DEFAULT_DATA.endings` 의 E2 코드가 `쇼트브레드` 다 ③ `version` 이 32 다. 돌려서 셋 다 FAIL 을 본다.

- [ ] **2. 고친다**

`.ticker` 를 `top` 계산 대신 아래쪽 고정으로 바꾸고(`bottom` 사용), `paintTick()` 의 `o.offsetTop…` 줄을 지운다. E2 코드를 `쇼트브레드` 로. `version` 을 32 로.

- [ ] **3. 빌드하고 검사를 돌린다**

`python3 tools/build.py && python3 tools/tvtest.py` → 전부 `OK`.

- [ ] **4. 커밋·푸시**

### 과제 3: 특수 카드 여섯 장 — 티비

**파일:** 고친다 `tv/source.html` (`DEFAULT_DATA`, `clickPhoto()`, `renderPhoto()`/`renderBig()` 의 `cap`, 제작자 모드)

**쓰는 것:** 과제 2 의 version 32.

**내보내는 것:** `DEFAULT_DATA.specials` — `[{id,title,kind,act,only,text}]`. `kind` 는 `증언`·`국과수`·`일기장`. `only` 는 없으면 둘 다, `"D"` 면 형사만.

- [ ] **1. 검사부터 더한다**

`tools/tvtest.py` 에: ① `specials` 가 여섯 장이고 id 가 X1~X6 이다 ② X1 의 `only` 가 `"D"` 다 ③ `cards.K6.hotspots` 에 `card:"X1"` 인 지점이 있다 ④ `cards.G3.text` 에 `비밀 ③` 이 없다 ⑤ `cards.G1.text` 에 `X6` 이 있다. 돌려서 FAIL 을 본다.

- [ ] **2. `specials` 여섯 장을 넣는다**

| id | kind | act | only | 거는 곳 |
| --- | --- | --- | --- | --- |
| X1 | 일기장 | 1 | D | K6 새 지점 (93,52) r6 |
| X2 | 증언 | 1 | — | K2 새 지점 (88,46) r7 |
| X3 | 국과수 | 1 | — | K6 있는 지점 (60,80) |
| X4 | 증언 | 2 | — | B5 새 지점 (63,16) r6 |
| X5 | 국과수 | 2 | — | B4 새 지점 (87,60) r8 |
| X6 | 국과수 | 3 | — | G1 본문의 `▣` |

본문은 설계 문서의 "빌더에게 남기는 것" 을 지킨다. 특히: 반지하는 미제여야 하므로 두 번째 잔에 지문·타액이 남지 않았다고 쓴다. 옆집 증언에는 "경찰이 5분 만에 왔다"를 넣는다.

- [ ] **3. 지점에 카드를 매단다**

해당 핫스팟에 `card` 를 넣는다. 새 지점 넷은 위 표의 좌표로 더한다.
`G1.text` 끝에 `▣ 국과수 감정서 X6을 꺼낸다` 를, `G3.text` 에서 `▶ 형사: 비밀 ③을 읽는다` 를 지운다.

- [ ] **4. 지시를 띄운다**

`renderPhoto()`·`renderBig()` 의 `cap` 에서, 찾은 지점에 `card` 가 있고 (`only` 가 없거나 `only===me()`) 이면 설명 아래에 `▣ <kind> 카드 <id>를 꺼낸다` 한 줄을 더한다. `only` 가 안 맞으면 그 줄을 빼고 설명만 보인다.
`clickPhoto()` 의 `log()` 문구도 같은 규칙을 따른다.

- [ ] **5. 제작자 모드에 본문을 보인다**

제작자 모드에 `specials` 본문을 읽기 전용으로 한 덩어리 띄운다. 플레이 화면에는 넣지 않는다.

- [ ] **6. 빌드하고 검사를 돌린다**

`python3 tools/build.py && python3 tools/tvtest.py` → 전부 `OK`.

- [ ] **7. 커밋·푸시하고 아티팩트에 게시한다**

`tv/source.html` 을 게시한다. 거절되면 거절 메시지의 새 판을 저장소 파일에 합치고 다시.

### 과제 4: 특수 카드 여섯 장 — 인쇄

**파일:** 고친다 `cards/cards.py`, `cards/make_pdf.py`

- [ ] **1. `ACT` 에 `'X'` 를 더한다**

`'X':('특수 카드',(150,140,190))`.

- [ ] **2. `CARDS` 에 X1~X6 을 더한다**

`kind='special'`. 앞면은 번호·종류·제목, 뒷면은 본문. 본문은 과제 3 의 `specials` 와 글자까지 같게 한다.

- [ ] **3. `front()`·`back()` 에 `special` 갈래를 더한다**

앞면은 코드 자리에 `증언`·`국과수`·`일기장` 을 넣고, 일기장에는 `형사만 읽는다` 를 덧붙인다. 뒷면은 엔딩 카드의 본문면과 같은 틀을 쓴다.

- [ ] **4. 뽑아서 본다**

`python3 cards/cards.py && python3 cards/make_pdf.py` → `png/` 에 28장, PDF 가 28장(A4 넉 장 분량), 앞뒤 전체비교 PNG 가 28장.

- [ ] **5. 커밋·푸시**

# 엔딩 갈래 · 질문 고정 · 취조서 문서 · main 검사 장치 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3막 두 질문을 누가 맞혔는지로 엔딩 갈래(자수 / 연쇄 살인마 / 히든 / 미도달)를 나누고, 막의 질문·엔딩을 저장소 설계로 고정하고, 룰북·카드 탭을 지금 판결 화면에 맞추고, `main` 을 지키는 검사 장치(`tools/check.py` + pre-push 훅 + GitHub Actions)를 만든다.

**Architecture:** 갈래 계산은 티비(`tv/source.html`)의 `route()` 한 함수에 모으고 판결 화면·자수서 잠금·엔딩 부르기가 그것만 본다. 질문은 이름표(`key`)로 찾는다. 검사 장치는 기존 `tvtest.py`·`docstest.py` 에 `consistency.py` 를 더해 `check.py` 가 차례로 부른다.

**Tech Stack:** 단일 HTML(바닐라 JS), Python 3 + Playwright, Pillow/ReportLab(`cards/`), GitHub Actions(ubuntu, Python 3.12).

**Spec:** `docs/superpowers/specs/2026-11-25-엔딩-갈래-검사-design.md`

## Global Constraints

- `CLAUDE.md` 그대로: 고치기 전 `git pull --rebase origin main`, 수정 하나 = 커밋 하나, 바로 `main` 푸시, `--force` 금지.
- 점수표·`VGRID`·엔딩 1~9의 문장은 바꾸지 않는다.
- 히든 엔딩: id `E10`, 쿠키 이름 「마들렌」, 제목 「그녀의 이야기」, `"hidden":true`, 뒷면 "엔딩 책자의 「그녀의 이야기」를 읽는다".
- 질문 이름표: 범인의 3막 질문 `"key":"herReason"`, 형사의 3막 질문 `"key":"bridge"`.
- 「시간이 끝났다 — 판결로 간다」: 3막에서만, 두 번 눌러야, 되돌릴 수 없음, 넘어가면 형사의 질문은 닫힘.
- 갈래: 둘 다 → 자수서 세 칸 + 고른 엔딩 뒤 「마들렌」 / 범인만 → 세 칸 / 형사만 → "쓰지 못했다"만 / 둘 다 못 → "쓰지 못했다"만, 엔딩은 취조서와 무관하게 E4(「머랭」).
- 카드 총수 31장(63×88mm 26 · A6 5). 그녀가 어머니를 죽였다는 문장은 어디에도 넣지 않는다.
- 설계 버전 `DEFAULT_DATA.version` 은 pull 받은 값 + 1.
- 라틴 대문자 라벨 금지(CLAUDE.md 8절) — 카드·화면 문구는 한국어.

## Review Focus

1. 판결 화면에 들어간 뒤 범인이 답을 맞혀 갈래가 바뀔 때 — 잠금·갈래 한 줄·엔딩 부르기가 함께 바뀐다(이미 엔딩이 불렸으면 "처음부터 다시 적는다"를 권하는 알림).
2. 「시간이 끝났다」를 한 번만 누르고 다른 채널로 갔다 오면 — 두 번째 누름 대기가 풀려 있어야 한다(실수로 넘어가지 않게).
3. 옛 저장 설계(버전 낮음·`memory` 에 `key` 없음)·제작자 JSON 으로 `memory` 를 바꾼 경우 — 티비는 저장소 질문을 쓰고, 갈래 계산이 오류 없이 돈다.
4. 둘 다 못 맞힘 + 취조서 "동생의 이름" — 엔딩은 E4 하나만 불린다(E5 아님).
5. 검사 장치를 크롬이 없는 컨테이너·GitHub 러너에서 돌릴 때 — 둘 다 Playwright chromium 으로 돈다.

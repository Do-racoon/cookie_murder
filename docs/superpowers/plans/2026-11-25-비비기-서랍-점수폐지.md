# 비비기 · 서랍 문 · 점수 폐지 · 50분 — 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 형사가 서랍(비밀 ③)을 열어야 1막이 넘어가게 하고, 사진 비비기 힌트를 넣고, 점수를 없애고 타이머를 50분으로 바꾼 뒤 게시한다.

**Architecture:** 티비(`tv/source.html`) 한 파일에 막 전환 문(`gate`)·비비기(포인터 이벤트 + 빛)·엔딩 안내를 넣는다. 기획서·핸드아웃은 Claude 문서에서 고쳐 `text/`로 내보내고, 문서 모음은 `text/기획서.md`에서 기획서 탭을 다시 그린 뒤 나머지를 손으로 고친다. CI는 고정된 `tools/requirements.txt`를 쓴다.

**Tech Stack:** 바닐라 JS 단일 HTML, Python 3 + Playwright(`tools/tvtest.py`), `tools/check.py`, Claude Docs 커넥터, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-25-비비기-서랍-점수폐지-design.md`

## Review Focus

1. 질문을 다 맞힌 뒤 서랍을 **범인 시점(두 폰 판의 C)** 으로 눌러도 막이 넘어가야 한다.
2. 서랍을 질문보다 **먼저** 연 판 — 질문 둘을 맞히는 순간 바로 2막이어야 한다(문 안내가 뜨면 안 된다).
3. 비비기 도중 손을 뗀 위치가 지점 위여도 **누르기(지점 열기)가 일어나면 안 된다**; 짧은 누르기는 지금처럼 열려야 한다.
4. 이미 찾은 지점은 비벼도 빛나지 않는다; 사진이 없는 글 카드에서 비비기는 오류 없이 아무 일도 없다.
5. 옛 저장 판(1막 질문 둘만 맞히고 멈춘 판)을 열고 서랍을 누르면 2막으로 간다.

### Task 2: 티비 — 비비기

**Files:** Modify `tv/source.html` (사진 레이어 이벤트 연결 두 곳: 본 화면 `.photo[data-id]`, 확대 시트 `.photo`; CSS), `tools/tvtest.py`.

**Interfaces:**
- Produces: `bindRub(ph: Element, id: string)` — 사진 요소에 포인터 이벤트를 달고, 비비기 판정·빛·click 억제를 맡는다. 기존 `ph.onclick=ev=>clickPhoto(...)` 는 그대로 두고, 비비기로 끝난 직후의 click 한 번만 막는다.
- 상수: `RUB_MIN=0.06` (레이어 너비 비율), `RUB_PAD=4` (% 단위, 반경 r 에 더함), `GLOW_MS=1500`.

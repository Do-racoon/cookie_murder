# 세 화면을 한 옷으로 — 디자인 통일 설계 (2026-11-24)

사용자 승인: 방법 C. "한 옷으로 맞추는 게 맞다. 티비가 메인이니 그것에 맞췄으면 좋겠다."

## 왜

「쿠키 살인 사건」은 보는 곳이 셋이다 — 티비(웹), 인쇄 카드, 문서 모음(공모전 심사용).
지금 셋이 서로 다른 옷을 입고 있다.

| | 지금 |
| --- | --- |
| 티비 | 나무 캐비닛 · 녹색 인광 유리 · 호박색. 나눔고딕코딩 + VT323 + 고운바탕 |
| 카드 | 짙은 남색 사건 파일 · 주황 악센트. Noto Sans CJK |
| 문서 모음 | 크림색 종이 · 먹색 · 붉은 악센트. Noto Serif KR. 다크모드 분기 있음 |

심사위원은 셋을 연달아 본다. 지금은 세 팀이 각각 만든 물건처럼 보인다.

## 목표

- 셋이 같은 색·같은 글꼴·같은 선 규칙을 쓴다. 기준은 티비다.
- 카드를 손에 들었을 때와 티비 화면을 볼 때 같은 글자꼴이 보인다.
- 색·글꼴 값이 한 군데에 적혀 있어서, 다음에 바꿀 때 세 곳을 따로 고치지 않는다.

## 하지 않을 것

- **티비는 손대지 않는다.** 티비가 기준이다. 티비의 값을 밖으로 옮겨 적을 뿐이다.
- **질감은 옮기지 않는다** — 스캔라인·유리 광택·나무결 바탕은 티비에만 남긴다.
  문서 모음은 심사위원이 15쪽을 읽는 곳이라 스캔라인 위에 긴 글을 올리면 피로가 멋을 이긴다.
  카드는 인쇄물이라 질감이 잉크로 뭉갠다. 나무결은 문서 모음 맨 위 띠 한 줄에만 쓴다.
- **내용은 건드리지 않는다.** 글·코드·카드 구성은 그대로. (예외 하나: 소개서의
  "카드 22장"이 31장으로 틀렸다 — 같이 고친다.)
- 엔딩·특수 카드의 구조나 판결 흐름은 이 작업에서 바꾸지 않는다.

## 제약

- `tv/source.html`이 티비의 원본이고, 이 작업에서 읽기만 한다.
- 카드는 PIL(Pillow)로 그린다 — CSS를 못 읽는다. 색·글꼴 값을 기계가 읽을 수 있는
  형태로 둬야 두 쪽이 같은 값을 쓴다.
- 인쇄: 카드는 지금도 어두운 바탕이라 잉크량은 그대로다. 문서 모음은 화면용으로
  어둡게 가되, 인쇄할 때는 밝은 바탕·검은 글씨로 나오게 한다(심사위원이 PDF로 뽑을 수 있다).
- 저장소 용량: 글꼴 파일을 넣어야 어디서든 카드가 다시 뽑힌다.
- 커밋 하나 = 수정 하나, 바로 `main`에 푸시, `--force` 금지. `submission-2026-11-22/`는 손대지 않는다.

## 고른 방법 — 값을 한 파일에 적고, 세 곳이 그걸 쓴다

`design/tokens.json` 하나에 색·글꼴·선 값을 적는다. 티비에서 뽑은 값이다.
- 문서 모음(`docs/index.html`)은 거기서 생성한 `docs/tokens.css`를 쓴다.
- 카드(`cards/cards.py`)는 `tokens.json`을 직접 읽는다.
- 티비는 지금 값을 그대로 둔다. 대신 **검사**를 하나 둔다 — 티비의 CSS 변수와
  `tokens.json`이 어긋나면 `tools/tvtest.py`가 FAIL을 낸다. 어긋남이 조용히 쌓이지 않는다.

### 생각했던 다른 길

- **A. 색·글꼴만 각 파일에서 직접 바꾼다.** 제일 빠르다. 하지만 값이 세 군데에
  흩어진 채라, 다음에 색 하나 바꾸려면 또 세 곳을 고쳐야 한다. 이미 `졼트브레드`로
  한 번 데였다 — 같은 값이 두 곳에 손으로 적혀 있으면 반드시 어긋난다. 버렸다.
- **B. 티비를 액자로 쓴다.** 문서 모음을 브라운관 안에 넣고 카드에도 유리 질감.
  제일 한 작품 같아 보이지만, 읽는 물건과 인쇄물을 망친다(위 "하지 않을 것"). 버렸다.
- **티비가 tokens.json을 읽게 한다.** 원본이 한 곳이 되어 가장 깨끗하다. 그러나 티비는
  지금 잘 돌고 심사 제출본의 중심이다. 빌드에 주입 단계를 넣다가 티비를 깨뜨릴 위험이
  이득보다 크다. 검사로 묶어 두는 쪽을 골랐다.

## 디자인 체계

### 색 (티비에서 뽑는다)

| 이름 | 값 | 어디에 |
| --- | --- | --- |
| `bg` | `#0b0908` | 가장 바깥 바닥 (티비 `--room`) |
| `panel` | `#141a14` | 글이 올라앉는 면. 티비 유리(`--glass #0c140f`)보다 한 단계 밝게 — 긴 글을 읽어야 한다 |
| `raise` | `#1b211a` | 표 머리, 카드 안쪽 패널 |
| `line` | `#2f3a2e` | 경계선 |
| `phos` | `#d8f0c8` | 본문 글자 (티비 `--phos`) |
| `phos-dim` | `#8aa184` | 흐린 글자. 티비 `--phos-dim #6f8a68`보다 밝게 — 어두운 바탕에서 대비를 확보한다 |
| `amber` | `#e7b55a` | 강조 · 제목 · 링크 · 고른 탭 (티비 `--amber`) |
| `amber-hi` | `#ffd98a` | 강한 강조 |
| `red` | `#c2463c` | 3막 반지하 · 경고 (티비 `--red`) |
| `ochre` | `#c69a5b` | 1막 현행범 (티비 `--ochre`) |
| `slate` | `#8ca6b4` | 2막 맥주집. **티비에 없는 값** — 지금 카드의 청회색(`#8caaba`)을 체계에 맞게 다듬어 새로 넣는다 (내 판단) |
| `violet` | `#a98be0` | 특수 카드 (티비 `--violet`) |
| `wood` / `wood2` | `#5b3a21` / `#2e1a0e` | 문서 모음 맨 위 띠 한 줄에만 |

막 색이 지금 카드와 달라지는 것: 현행범 `(214,128,74)` → `ochre`, 맥주집 `(140,170,186)` → `slate`,
반지하 `(190,64,72)` → `red`, 자수서·엔딩 `(190,170,120)` → `amber`, 특수 `(150,140,190)` → `violet`.

### 글꼴 — 티비의 셋을 그대로

| 쓰임 | 글꼴 | 비고 |
| --- | --- | --- |
| 본문·설명·엔딩 장면 | **고운바탕** (Gowun Batang) | 티비 `--serif` |
| 라벨·표·코드·카드 제목 | **나눔고딕코딩** | 티비 `--mono` |
| 카드 번호·숫자 (`K6` `X1` `E1`) | **VT323** | 티비 `--digit` |

**VT323은 라틴 전용이다.** 카드 코드는 `8ㅎ8ㅎ`처럼 숫자와 한글 자음이 섞여 있어
VT323으로는 한글이 빈 네모로 나온다. 티비도 같은 이유로 한글은 나눔고딕코딩으로 떨어진다.
그러니 **코드는 나눔고딕코딩**, VT323은 **라틴·숫자만 있는 카드 번호**에만 쓴다.
이러면 카드에서 본 글자꼴이 티비 화면에도 그대로 나온다 — 이 작업이 노리는 바로 그 효과다.

글꼴 파일은 npm `@fontsource/*`에서 받아 woff2를 ttf로 바꿔 저장소에 넣는다.
고운바탕 전체는 8MB라 크다 → **카드에 실제로 쓰이는 글자만 추려(subset) 넣는다.**
추리는 과정은 스크립트로 두어 글이 바뀌면 다시 만들 수 있게 한다. (내 판단: 저장소를 가볍게)

### 문서 모음

- 바탕 `bg`, 본문 면 `panel`, 글자 `phos`, 제목·링크·고른 탭 `amber`.
- 맨 위 4px 나무결 띠 한 줄(`wood`→`wood2`) — 티비 캐비닛을 한 번만 인용한다.
- 탭은 티비 채널 목록처럼 **번호 + 이름**, 고른 것만 `amber`에 얇은 밑줄.
- 본문 16–17px, 줄 간격 1.75. 어두운 바탕에서는 밝은 바탕보다 줄 간격이 더 필요하다.
- 지금 있는 다크모드 분기(`prefers-color-scheme`)는 지운다 — 이제 어두운 게 기본이다.
- `@media print` 를 새로 넣는다: 흰 바탕·검은 글씨·띠 제거.

### 카드

- 바탕을 남색에서 티비 유리의 어두운 녹(`bg`/`panel`/`raise`)으로.
- 주황 악센트를 `amber`로. 막 색은 위 표대로.
- 본문은 고운바탕, 라벨·코드는 나눔고딕코딩, 카드 번호는 VT323.
- 레이아웃(앞면의 제목·설명·힌트·코드 자리, 뒷면 구성)은 **바꾸지 않는다** — 색과 글꼴만.
  현장 카드 14장의 뒷면은 11/22 제출본에서 꺼낸 그림이라 그대로 둔다.

## 검토에서 정한 것 (내 판단)

1. **티비와 대조하는 범위.** `tokens.json` 전부가 아니라, 티비에서 그대로 가져온 값만
   검사한다 — `bg` `phos` `amber` `red` `ochre` `violet` `wood` `wood2`.
   `panel` `raise` `line` `phos-dim` `slate`는 일부러 티비와 다르게 정한 값이므로 검사하지 않는다.
   (그러지 않으면 검사가 처음부터 FAIL이다.)
2. **문서 모음 탭 번호는 `01`~`09`, VT323.** 티비 채널 목록의 생김새를 가져온다.
3. **글꼴 subset에 빠진 글자가 있으면 카드 빌드가 멈춘다.** 나중에 카드 글을 고치고
   subset을 다시 안 만들면 빈 네모가 인쇄되는데, 그걸 눈으로 잡을 수는 없다.
4. **현장 카드 14장의 뒷면 그림(`cards/ext/`)을 버리고 전부 생성한다.**
   확인해 보니 그 그림들은 `back_button()`이 그리는 것과 **같은 디자인**이고, 제출본 PDF에서
   꺼내느라 재단선과 페이지 여백 얼룩이 가장자리에 묻어 있다. 생성 쪽이 더 깨끗하고,
   새 팔레트가 31장 전부에 고르게 입는다. 저장소도 848KB 가벼워진다.
   (11/22 제출본 파일 자체는 `submission-2026-11-22/`에 그대로 있다.)

## 감수하는 것

문서 모음은 공모전 심사위원이 기획서를 읽는 곳이다. 어두운 바탕은 한 작품처럼 보이게
하지만, 밝은 바탕보다 긴 글을 읽기 불편하다는 사람도 있다. 그래서 본문 크기·줄 간격을
지금보다 키우고, 인쇄할 때는 밝은 바탕으로 나오게 한다. 그래도 심사에서 이게 불리하다고
판단되면 문서 모음만 되돌리는 건 쉽다 — 값이 한 파일에 있으니 그 파일만 바꾸면 된다.

## 빌더에게 남기는 것

- `tokens.json`의 정확한 구조(키 이름, 중첩 여부).
- 문서 모음 탭의 번호 매김 방식과 좁은 화면에서의 줄바꿈.
- 글꼴 subset에 넣을 글자 집합을 어떻게 모을지(카드 본문 전체 + 라벨 고정 문구).
- 카드에서 `phos`(#d8f0c8)를 본문 글자색으로 그대로 쓸지, 인쇄를 고려해 살짝 누른 값을 쓸지 —
  뽑아 보고 정한다.

## 고침 (2026-11-24 저녁) — 카드는 종이다

사용자 지적: "카드 디자인이 사이버펑크 같지 않아? 우리 장르는 1990년대에서 2010년대인데."
맞는 지적이었다. 위 설계의 전제 하나가 틀렸다.

**무엇이 틀렸나.** 티비의 *화면*을 종이에 옮겼다. 화면은 빛나는 물건이라 검은 바탕에
인광색이 맞지만, 카드는 종이다. 검은 종이에 가는 빛 선과 밝은 호박색 숫자를 올리고
`CASE FILE`·`PHOTO EVIDENCE`·`HINT` 같은 라틴 대문자 라벨을 붙이니 터미널 화면이 됐다.
작중에서 이 카드들은 사건 기록 사진·국과수 감정서·진술조서·일기장·손으로 쓴 자수서다.
1990~2010년대 한국에서 저것들은 전부 종이다.

**무엇으로 바꿨나.** 셋을 묶는 것은 같은 색이 아니라 **같은 세계의 재료**다 —
나무, 종이, 전등 불빛, 그리고 유리 한 장. 그 방에서 빛나는 물건은 티비 하나뿐이다.

- `tokens.json` 이 두 벌을 갖는다: `color`(티비 유리 쪽, 티비와 대조함)와
  `paperColor`·`paperAct`(종이 쪽). 종이의 먹은 화면의 빛보다 어둡다 — 같은 색상, 다른 재료.
- 카드: 미색 종이(`#e9e1d0`)에 먹색 글씨, 막 색은 위쪽 띠, 코드는 도장 친 네모 안.
  뒷면은 크라프트색 서류철 겉장에 막 이름이 찍힌 도장.
- 라틴 대문자 라벨을 한국어로: `CASE FILE`→`사건 기록`, `PHOTO EVIDENCE`→`현장 사진`,
  `HINT`→`눈여겨볼 것`, `ENDING`→`엔딩`.
- 문서 모음: 바깥(방·머리글·탭)은 어두운 채로 두고, 읽는 면만 종이로 뒤집었다.
  `:root` 가 방 색, `.panel` 이 같은 이름들을 종이 색으로 덮는다.
- 고운바탕은 그대로 둔다 — 90년대 한국 인쇄물의 명조라 오히려 시대가 맞는다.

덤: 종이 바탕이라 집에서 뽑을 때 잉크가 훨씬 덜 든다.

# 어머니 문장 빼기 · 미룬 작은 것 정리 — 짧은 설계 (2026-11-26)

사용자 승인: "진행해"(11/26 08:59). CLAUDE.md 7절 "그녀가 어머니를 죽였다는 것은 어디에도 쓰지 않는다"를 지킨다.

## 접근
- 플레이어용(핸드아웃 「그녀의 이야기」)과 심사·제작용(기획서, 문서 모음, 타임라인)에서 모두 뺀다 — "어디에도" (사용자가 권한 쪽을 승인).
  다른 안(기획서에는 진실을 남김)은 규칙과 어긋나 버림.
- 핸드아웃 해설: "…알게 된 그 날이 왔다. 그날 밤, 그녀는 식탁에 앉아 어머니가 항상 주었던…" — 누구의 피인지는 쓰지 않는다.
- 기획서: 인물 "부모를 죽인 뒤" → "부모가 죽은 뒤", 타임라인 행의 손 "그녀" → "—", 비고 "엔딩 책자에서 짐작만 하게 둔다".
- 문서 모음 핸드아웃 탭 요약 "부모를 죽인 것도 그녀라는 사실이 여기서 처음 밝혀진다" → 짐작만, 타임라인 페이지 설명도 같게.
- 다시 나오지 않게 `consistency.py` BANNED 에 "어머니를 죽였", "부모를 죽인" 을 더한다.

## 미룬 것
1. 크게 보기(⤢)에서 이어지는 사진을 닫으면 크게 보기로 돌아간다.
2. 저장 판(S)에 `ver`(설계 version)를 붙인다. `ver` 가 없거나 40 아래면 지점이 바뀐 카드 K2·K4·K5·K6·B1·B3·B5 의 found·misses 를 비운다. 지점 번호 옮겨 맞추기는 쓰지 않는다(틀릴 곳이 많음).
3. 링크 없는 옛 사본 `docs/rel/` 을 지운다.
4. 티비 아티팩트에서 안 쓰는 사진(bridge-rail, cctv-store, living-room, orphanage)을 내린다. room-strap 은 쓰고 있어 남긴다 *(제 결정 — 리뷰어 목록과 달리 source 가 참조함)*.

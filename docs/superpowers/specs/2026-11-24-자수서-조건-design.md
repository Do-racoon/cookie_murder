# 자수서는 일기장으로 연다 — 설계 (2026-11-24)

작은 변경. 사용자 승인: "C로 하자", "점수표는 일단 보류 그리고 일단 진행".

## 왜

판결 규칙이 문서마다 달랐다. 기획서는 "그녀의 이름을 들었을 때만 자수서", 티비는 언제든 자수서.
4막 진입은 형사의 질문(다리)으로 바뀌었는데 문서에는 "4막 미도달 = 이름 못 들음"이 남아 있었다.
형사가 1막부터 쥐는 일기장(X1)이 결말까지 이어지게 한다.

## 정한 것

- 범인은 3막 범인의 질문 "그녀는 왜 쿠키를 먹을까"를 맞혀야 자수서 S1·S2를 낼 수 있다.
  못 맞히면 "못 냄" → 엔딩 3·4·5.
- 티비 판결 화면: 맞히기 전에는 S1·S2 버튼을 잠그고 이유를 한 줄로 보인다.
- 이름은 더 이상 열쇠가 아니다. "그녀의 이름을 들었다면", "4막 미도달 = 못 냄"을
  "마지막 질문을 맞혔다면 / 못 맞혔다면"으로 바꾼다. 범인 목표의 "그 애 이름"은 이야기 목표로 남는다.
- 진실 도달 ①: "발인 날 사라진 사람에 답했다" → "형사의 마지막 질문(다리)에 답했다".
- 문서: 기획서 8·10절, 핸드아웃 목표 문구, 문서 모음 룰북 탭(엔딩 9장, 특수 카드, 자수서 조건).

## 다른 길

- A 이름을 들었을 때만: 형사의 침묵이 지배 전략(1차 테스트 지적). 버림.
- B 언제든: 일기장이 결말에 영향이 없다. 버림.

## 하지 않을 것

- 점수표는 보류 — 고치지 않는다.
- 엔딩 9장의 조합표(VGRID)는 그대로.
